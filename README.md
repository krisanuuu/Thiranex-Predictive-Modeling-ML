# Thiranex Internship — Predictive Modeling Using Machine Learning

## Objective
Train and evaluate supervised machine-learning classifiers to predict employee attrition.

## Models
- Logistic Regression
- Decision Tree
- Random Forest

## Dataset
`data/employee_attrition_synthetic.csv` contains 600 synthetic records created for this project. It is not real employee data and is intended only for demonstration/learning.

## Features
- Dataset preview
- Train/test split (80/20)
- Model selection
- Accuracy metrics
- Confusion matrix
- Classification report
- Model comparison chart
- ROC curve

## Run locally
```bash
pip install -r requirements.txt
streamlit run main.py
```

## Project structure
- `main.py` — interactive Streamlit application
- `data/` — synthetic dataset
- `outputs/` — evaluation results and charts
- `PROJECT_REPORT.md` — report

## Disclaimer
The dataset and results are synthetic. Use a real dataset if the internship tutorial or submission guidelines require one.
